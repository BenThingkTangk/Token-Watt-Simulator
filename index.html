Model logic

  • Tokens / user / day = requests / user / day × total tokens / request
  • Effective watts = baseline watts × peak stress × (1 − optimized share × power reduction)
  • Tokens / watt / user = tokens / user / day ÷ watts / user
Model note

This simulator is directional. It does not claim audited facility power draw, rack-level telemetry, or vendor-certified cost accounting. It is intended to compare a centralized baseline against a convergence-layer scenario under the same workload assumptions.

What moves this number?
  • Higher requests per user increases token volume quickly.
  • Larger prompts raise token throughput but can also raise watt pressure.
  • Edge offload reduces centralized user-path power demand.
  • Semantic cache hit rate compresses repeat-token compute.
  • Peak-hour stress penalizes centralized delivery first.
